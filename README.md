# OneTap Login

Android-приложение: список ваших приложений и сайтов с быстрым входом.
Логины и пароли хранятся в зашифрованном хранилище (AndroidX Security),
само приложение открывается по отпечатку пальца или PIN-коду телефона.

[![Build APK](../../actions/workflows/build.yml/badge.svg)](../../actions/workflows/build.yml)

## Возможности
- Вход в приложение по биометрии (BiometricPrompt) или PIN/паролю экрана блокировки; повторная блокировка при выходе из приложения.
- Добавление **любых установленных приложений** (выбор из списка) и **сайтов** (по адресу).
- Изменение названия и адреса записи (сохранённые данные переносятся).
- Удаление записей вместе с сохранёнными данными.
- Импорт паролей из Google: экспортируйте CSV на passwords.google.com (Настройки → Экспорт) и выберите файл в приложении. Автоматический импорт без файла невозможен — у Google нет для этого API.
- Сервис автозаполнения Android: подставляет логин и пароль в приложениях (по package name) и в браузерах (по домену сайта).

## Скачать APK
Готовый debug-APK собирается автоматически:
- **Releases** — при публикации тега `v*` (например, `v0.3.0`) APK прикрепляется к релизу.
- **Actions → Build APK → Artifacts** — сборка любого коммита.

Для установки разрешите установку из неизвестных источников.

## Сборка локально
Нужны JDK 17 и Android SDK (Platform 36).
```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```
Или откройте проект в Android Studio и выберите Build → Build APK(s).

## Использование
1. Установите APK и разблокируйте приложение отпечатком или PIN-кодом.
2. Нажмите «+ Добавить», выберите приложение или введите адрес сайта.
3. Удерживайте карточку → «Логин и пароль», чтобы сохранить данные.
4. Включите автозаполнение: Настройки Android → Пароли и автозаполнение → OneTap Login.

## Ограничения
- Автозаполнение работает только там, где приложение или сайт используют стандартные поля ввода. Игры, Google, Telegram, Steam могут использовать собственные экраны, WebView, OAuth, QR или коды подтверждения — это не обходится.
- Для сайтов автозаполнение работает в браузерах, которые поддерживают сторонние сервисы автозаполнения (в Chrome это нужно включить в его настройках).
- Автозаполнение подставляет данные без повторной биометрии; биометрия защищает только вход в само приложение.
- Проект — MVP. Не используйте как единственное хранилище важных паролей без собственной проверки безопасности.

## Безопасность
Не публикуйте в репозитории свои пароли и ключи подписи (`*.jks`, `*.keystore` в `.gitignore`).
О найденных уязвимостях сообщайте через GitHub Security Advisories.
